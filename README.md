# Web Application for Placement Cell

## Overview

This Web Application is designed to streamline and manage the placement process at educational institutions. The system provides distinct modules for recruiters, students, and placement officers to manage placements efficiently. Additionally, it includes an automated resume screening feature using **PyResparser** to enhance the candidate evaluation process.

## Features

### Recruiter Module

- **Company Registration**: Recruiters can register their companies and create profiles.
- **Job Posting**: Post job openings with detailed descriptions and requirements.
- **View Applications**: Access and manage applications submitted by students.

### Student Module

- **Profile Management**: Create and update personal and academic profiles.
- **Job Applications**: Browse and apply for job opportunities posted by recruiters.
- **Resume Upload**: Upload resumes for automated screening.
- **View Application Status**: Track the status of job applications.

### Placement Officer Module

- **Dashboard Overview**: Access a dashboard with insights into job postings, applications, and student placements.
- **Manage Job Openings**: Approve or reject job postings submitted by recruiters.
- **Student Management**: View and manage student profiles and applications.
- **Communication Tools**: Facilitate communication between students and recruiters.

### Resume Screening with PyResparser

- **Automated Resume Parsing**: Use PyResparser to extract key information from resumes.
- **Keyword Matching**: Automatically match candidates to job descriptions based on relevant keywords.
- **Scoring and Ranking**: Score resumes based on predefined criteria and rank candidates accordingly.

## Technologies Used

- **Frontend**: HTML, CSS, Bootstrap, Javascript
- **Backend**: Node.js, Express.js, ejs, Python, PyResparser
- **Database**: MySQL
